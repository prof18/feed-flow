Which platforms is FeedFlow available on?

  • Android: Google Play and F-Droid
  • iPhone and iPad: App Store, iOS and iPadOS 17 or later
  • macOS: App Store, Macs with Apple silicon
  • Windows: Microsoft Store or the installer from GitHub releases
  • Linux: Flathub, plus .deb, .rpm and AppImage packages from GitHub releases

A few things aren’t available:

  • Web version: browsers can’t download most feeds directly, and FeedFlow has no server to do it for them.
  • Intel Macs: the frameworks FeedFlow is built with are dropping support for Intel Macs, so only Apple silicon is supported.
  • Android APK on GitHub: install from Google Play or F-Droid. Obtainium can track the F-Droid release.

The .deb package targets Debian 13 and distributions based on it. On older distributions, use the Flatpak or the AppImage.

Version numbers can differ between platforms: each platform gets its fixes as soon as they’re ready, without waiting for the others.
